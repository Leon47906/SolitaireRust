# SolitaireRust 🃏

A fully playable Klondike Solitaire game built with **Rust** and **WebAssembly**, rendered on an HTML5 Canvas.

***

## Project Structure

```
solitaire/
├── solitaire-core/      # Pure Rust game logic (no_std compatible)
├── solitaire-wasm/      # wasm-bindgen bindings exposing the game to JavaScript
└── web/                 # Frontend: HTML5 Canvas renderer + game input
    ├── index.html
    ├── main.js
    └── pkg/             # Generated by wasm-pack (do not edit)
```

***

## Tech Stack

| Layer | Technology |
|---|---|
| Game logic | Rust (workspace crate `solitaire-core`) |
| WASM bindings | [`wasm-bindgen`](https://github.com/rustwasm/wasm-bindgen) |
| Serialization | [`serde`](https://serde.rs/) + [`serde-wasm-bindgen`](https://github.com/cloudflare/serde-wasm-bindgen) |
| Frontend | Vanilla JavaScript, HTML5 Canvas |
| Build tool | [`wasm-pack`](https://rustwasm.github.io/wasm-pack/) |

## Getting Started

### Prerequisites

- [Rust](https://rustup.rs/) (stable toolchain)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/)
- A local HTTP server (e.g. Python's built-in server)

### Build

```bash
# From the workspace root
wasm-pack build solitaire-wasm --target web --out-dir ../web/pkg
```

### Run

```bash
cd web
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.

## How to Play

| Input | Action |
|---|---|
| **Click** deck | Draw a card to the waste pile |
| **Click** empty deck | Recycle waste back to deck |
| **Click** a card | Select it (highlights the card and any stack below it) |
| **Click** another pile | Move selected card(s) to that pile |
| **Right-click** | Deselect |
| **Shift + Click** | Auto-move card to foundation |
| **Shift + Alt + Click** | Auto-move card to best tableau column |

### Rules

- Build foundation piles from **Ace → King**, same suit.
- Build tableau columns in **descending rank**, **alternating colour**.
- Entire face-up stacks can be moved together.
- Empty tableau columns accept **Kings only**.
- Flip the deck up to three cards at a time; recycle when exhausted.

***

## Architecture

Game logic lives entirely in `solitaire-core` and is completely decoupled from the frontend. The `solitaire-wasm` crate is a thin binding layer that:

1. Wraps `SolitaireGame` in a `WasmGame` struct marked `#[wasm_bindgen]`
2. Exposes flat, primitive-typed methods (no complex types cross the WASM boundary)
3. Serialises game state to JSON via `serde` for the JS renderer

The JavaScript file is intentionally logic-free — it translates user input into WASM calls and renders the state it receives back.
